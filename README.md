# English Agent 🎓

美业英语私教：手机上用 ChatGPT 语音天天练口语，电脑上的 AI 编程助手
（Claude Code / OpenAI Codex）当教研大脑——批改、排期、备课。为 0 基础、
在美甲/美睫/美容行业工作的学习者定制。

## 快速开始

学习者与部署者都看 [使用说明.md](使用说明.md)（手机六步上课 + 电脑
复盘 + 快捷指令配置）。

## 工作原理

```
手机 ChatGPT（每天）                    Mac（每隔几天）
粘贴今日卡片 → 语音练习 → 复制战报 ──iCloud──→ 「复盘」：更新档案，生成明日卡片
        ↑ ──────────────────── iCloud ←──────────────┘
```
